# yuweiyang9611.github.io

项目目录，也是所有项目站点共用的设计语言。

访问地址：<https://yuweiyang9611.github.io/>

## 本地预览

页面不依赖构建工具，用任意静态服务器打开仓库根目录即可。网页字体只在正式域名上加载，本地会用已安装的思源黑体，没有就回退到系统字体。

## 项目列表

列表静态写在 `index.html` 中，页面加载时不请求 GitHub API。新增项目时直接加一行。

所有站点同域名，所以目录页可以读取各课程保存在浏览器里的学习进度，显示“接着做”、今日复习和连续学习天数。**它只读不写**，读取方式在 `script.js` 的 `courses` 和 `reviews` 中，课程改了存储格式就要同步修改这里。唯一的例外是“备份”里的恢复：读者选了备份文件、看过里面有哪些课、再点“覆盖并恢复”之后，才把文件里的记录写回去。算法研习室的进度在 IndexedDB 中（`dsa-learning-progress`），目录页先用 `indexedDB.databases()` 确认它存在才打开，不带升级回调，避免凭空建出一个空库把课程弄坏。

## 共享设计语言

`kit/v1/` 是各站共用的基础：

| 文件 | 用途 |
| --- | --- |
| `notebook.css` | 五色、字体、页头、记录线、贴入输出等基础样式 |
| `theme.js` | 白天和晚上配色切换，在正式域名上加载网页字体 |
| `fonts.css`、`fonts/` | 按需分片的思源黑体，常规和半粗两个字重（SIL OFL，见 `fonts/OFL.txt`） |

课程站点把 `notebook.css` 和 `theme.js` 各复制一份到自己的仓库，这样本地测试不依赖这里，部署也互不影响；字体体积较大，所有站点共用这里的一份。不兼容的改动放进新的 `kit/v2/`，不要改已发布的版本。

设计规则见 [DESIGN.md](DESIGN.md)，产品定位见 [PRODUCT.md](PRODUCT.md)。

## 部署

推送到 `main` 后，`.github/workflows/pages.yml` 先跑测试，再只发布网站文件。设计记录和测试不会上线。
